# 📘 DSA Top 170 Problems

This repository contains solutions to the **Top 170 DSA problems** that are frequently asked in coding interviews, competitive programming, and technical assessments.

The goal of this repo is to provide **clean, optimized, and well-structured code implementations** in Java (and later extendable to other languages if required).

---

## 📂 Repository Structure
- `src/` → Contains Java solution files for each problem (named by their problem number).
- `UpdatedPrepInstaCodes.txt` → Master list of all **170 problems** with their order and references.
- `PrepInsta.txt` → List of **prep insta top 100 problems**
- `README.md` → You are here.

---

## 🚀 Problems Covered
The problems span across major DSA topics:
- Arrays & Strings
- Searching & Sorting
- Matrix Problems
- Recursion & Backtracking
- Linked List
- Stack & Queue
- Dynamic Programming
